# How to use this atlas

This is the demo atlas of Cartographer: a small knowledge base about astronomy, written for agents and
people alike. Reply in **English** unless the operator writes in another language.

## Status convention

- `active` means the page is valid and current, not that work is open.
- In the observation log, a session is `planned`, `open` while notes are still coming, `done` when written up.
- A page replaced by a better one is `superseded`, with `superseded_by` naming its successor.

## Write discipline

- Cite a source from the `sources` journal in `provenance` for every number you add.
- When two sources disagree, record a Contradiction in `questions` instead of picking one.
