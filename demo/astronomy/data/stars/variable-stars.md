# Variable stars

Cepheids pulse with a period that reveals their true luminosity, as Henrietta Leavitt found in 1912. That makes them the first rung of the cosmic distance ladder, used to measure the [[galaxies/hubble-law|Hubble constant]]. [[stars/polaris]] and [[stars/betelgeuse]] both vary.
