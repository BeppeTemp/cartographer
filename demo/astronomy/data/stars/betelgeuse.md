# Betelgeuse

Betelgeuse is a [[stars/red-giant|red supergiant]] large enough to swallow the orbit of [[solar-system/mars]]. It
will end as a [[stars/supernova]], probably within the next hundred thousand years. In 2019–2020 it dimmed
sharply for months, an event now attributed to a cloud of dust it ejected.

Its distance is uncertain by tens of percent: see [[questions/betelgeuse-distance]]. Its neighbour across
Orion, Rigel, is described in [[stars/rigel]].
