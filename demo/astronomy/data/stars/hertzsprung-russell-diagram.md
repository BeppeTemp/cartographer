# The Hertzsprung–Russell diagram

Plotting stars by colour and brightness separates them into the [[stars/main-sequence]], the [[stars/red-giant|giants]] and the [[stars/white-dwarf|white dwarfs]]. It needs distances, which is why [[instruments/gaia]]'s [[glossary/parallax]] measurements sharpened it so much.
