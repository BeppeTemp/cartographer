# plan-observing-night

1. Read the observation log for what is still open.
2. Check the Moon's phase and the site's darkness ([[observing/measuring-sky-brightness]]).
3. Pick targets and the runbook for each, e.g. [[observing/planning-a-meteor-watch]].
4. Write the plan as a new entry in the observation log.
